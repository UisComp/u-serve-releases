# U-Serve Captain — downloads

Release builds of the U-Serve Captain Android app for handsets that are not
installed from Google Play. This repository holds **no source code**: each
release carries the signed APK, `update.json` (what installed copies check for
updates) and a download page.

**Permanent download link (always the latest release):**
https://github.com/UisComp/u-serve-releases/releases/latest/download/userve.apk

Releases are published automatically by the app's release pipeline. A handset
still needs an activation code from the provider before the app opens.

# U-Serve Captain — التحميل

نسخ تطبيق U-Serve Captain لأجهزة Android المثبتة من خارج Google Play.
لا يحتوي هذا المستودع على أي كود مصدري؛ كل إصدار يحمل ملف APK الموقّع وملف
`update.json` الذي تتحقق منه النسخ المثبتة لمعرفة التحديثات.

**رابط التحميل الدائم (أحدث إصدار دائماً):**
https://github.com/UisComp/u-serve-releases/releases/latest/download/userve.apk
